Additional manual/integration gates: inspect screenshots for clipping, contrast and believable fictional-site placement; verify keyboard focus through all controls; exercise browser Back/Forward and original Reno restoration (the integrated smoke test covers these); verify genuine WebGL context loss; repeat with the final integrated commit. Browser source-failure tests do not certify map-tile availability or a functioning 3D scene. Use the strict ready/mapTilesLoaded smoke alongside this independent workflow suite.

There is no live provider, email, model endpoint, hidden publication or hardware-FPS claim in these checks.
