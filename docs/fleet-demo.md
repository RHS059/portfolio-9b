# Fleet source-of-truth demo

The interactive case-study extension is served at `/fleet-demo`, with static assets under `public/fleet-demo/`. The original Fleet Manager Reno console remains available at `/fleet-demo/reno.html`. Its original HTML and generated `support.js` are unchanged.

The extension separates immutable synthetic import records and service facts from versioned, effective-dated authority/exclusion configuration and derived replay results. Anonymous providers A/B do not identify any actual vendor. Raw observations and import timestamps remain distinct. Missing, excluded, stale, invalid or conflicting authoritative data stays unresolved rather than silently choosing another source, the largest value, or the latest import.

## Develop and verify

- Run the portfolio normally (`pnpm dev`) and open `/fleet-demo`.
- For only the static demo: `cd public/fleet-demo && python3 -m http.server 8000`.
- Run its dependency-free tests: `node --test public/fleet-demo/tests/**/*.test.js`.
- The portfolio's existing dependencies and lockfile have not been upgraded.

The source renderer uses MapLibre 4.7.1 and Three r128, the same pinned major dependencies as the original Fleet Manager. It consumes snapshots from a 20 Hz visual clock and interpolates presentation at browser RAF. When WebGL is unavailable it provides a labeled 2D raster/SVG map and preserves the source controls. The primary vector map uses the same OpenFreeMap CDN as Grid Command, with OpenMapTiles/OpenStreetMap attribution. Camera mode changes, picking and visual culling cannot mutate source records.

`src/domain/readings/index.js` is the pure domain entry point. `createScenario({authorityApplied:false})` creates the guided starting state. TRK-104 has no authority, while unmigrated TRK-208 continues using A. An explicit B authority command resolves only the migrated vehicle. Commands, imports and replay are idempotent. Configuration changes append history, and service records are never regenerated by replay.

## Then / Today

Then shows explicit validation and source controls representing the 2021–22 design approach. Today adds an advisory review provider interface and in-app notifications. The default provider is clearly labeled deterministic simulated review, with no model call. The interface can accept separately verified recorded output. It passes a frozen snapshot to a provider, validates evidence IDs and drops arbitrary action fields. A review cannot change authority, raw records, service facts, or send external communications. No browser API credential is included.

## Accuracy and limits

The user-reported incident involved a partial provider migration, frozen readings from the previous provider, nightly conflicts, and repeated oil changes/tire rotations noticed by shop technicians. Exact historic readings, scheduler rules and financial loss are unknown. Dates, readings, assets, service facts and animations in this prototype are synthetic. Its illustrative freshness policy is documented in the fixture. The Oakland setting, drone assembly operation, workshop, traffic and movements do not represent live operations or as-built facility data.

RAF statistics describe only the current browser's observed cadence; they are not a certified CPU/GPU benchmark. The target is at least 30 FPS and ideally 60 FPS at 1080p on named hardware. A passing automated source test or software-rendered run does not establish that target.
